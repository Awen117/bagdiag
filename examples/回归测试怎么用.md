# 回归测试怎么用这套工具

以安全类停障测试（低矮箱体 / 锥桶 / 静止车）为例。

## 1. 拉包后先验完整性

```bash
bagdiag info ./test_run/
```

看三件事：时长是不是符合录制预期、消息数是否明显偏低、有没有零消息话题。
偏小的包可能是下载中断，必须重拉。

## 2. 停障结果

```bash
bagdiag stop ./test_run/
```

输出直接给判定：

```
最高车速 10.6 km/h   停稳: 是
减速 28.7 m / 12.9 s   峰值 -1.59 / 平均 -0.62 m/s²
停稳时最近目标 7.1 m   MRM NORMAL   AEB False
判定: PASS
```

判据（写在 `modules/stop.py` 里，可按项目改）：

- 停稳
- 停稳时最近目标 ≥ `BAGDIAG_MIN_STOP_GAP_M`（默认 2.0 m）
- 峰值减速度 ≥ −`BAGDIAG_MAX_DECEL_MPS2`（默认 4.0 m/s²）

两个阈值都在 `modules/stop.py` 顶部，按项目需要改即可。
- 无 AEB 介入
- MRM 全程 NORMAL

## 3. 规划有没有绕行

```bash
bagdiag avoid ./test_run/
```

```
路径横向最大偏移 0.24m（150 帧） → 直线（不绕）
```

<0.5m 说明规划选的是"直线停障"，不是"往边上让"。

## 4. 轨迹健不健康

```bash
bagdiag traj ./test_run/
```

如果看到 `点数<100 的帧: 100%` 且判定 `COLLAPSED`，先别急着怀疑校验代码 —— 新版规划器按固定周期出固定点数，静止时会退化成几十厘米，属于架构行为。

## 5. 有没有误触发急停

```bash
bagdiag mrm ./test_run/
```

正常应该 `MRM 触发 0 次`、只有一条 `None -> NORMAL`。

## 6. 把结果汇总

```bash
for d in ./test_run_*; do
  echo "== $d"
  bagdiag --json stop "$d" >> result.jsonl
done
```

拿到 `result.jsonl` 之后按 `verdict` 分组，就是当天的测试汇总。
